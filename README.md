# MH BizManager

MH BizManager est une application ERP/CRM développée par MH Digital Solution. Elle permet de gérer les clients, les factures, les devis, les paiements, les modes de paiement, les taxes et les paramètres de l'entreprise.

## Fonctionnalités

- **Dashboard** : Vue d'ensemble des indicateurs clés.
- **Clients** : Gestion des informations clients.
- **Factures** : Création et suivi des factures.
- **Devis** : Élaboration et gestion des devis.
- **Paiements** : Suivi des paiements reçus.
- **Modes de paiement** : Configuration des méthodes de paiement.
- **Taxes** : Gestion des taux de taxes applicables.
- **Paramètres** : Configuration générale de l'application.
